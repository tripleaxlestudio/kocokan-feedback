# Kocokan Feedback

Public feedback and issue tracker for Kocokan Alpha by Tripleaxle Studio.

Use this repository to:
- report bugs
- request features
- share feedback

Kocokan source code is maintained separately and is not published in this repository.

## Before reporting

Please do not include:
- participant names
- ticket numbers
- event datasets
- winner records
- private event information
- imported CSV/XLSX files
- confidential screenshots

For bug reports, include:
- Kocokan version
- what happened
- expected behavior
- reproduction steps
- screenshots only if they do not contain sensitive event data
